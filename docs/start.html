Начало работыGetting started

Установка мода, папка scriptcraft/, первый скрипт, команды перезагрузки и конфиг. Installing the mod, the scriptcraft/ folder, your first script, reload commands and config.

1. Установка1. Install

  • Нужны Minecraft 1.20.1 и Forge 47.x (Java 17).
  • Положите scriptcraft-<версия>.jar в папку mods сервера и всех клиентов: экраны, свои блоки и раздача текстур работают только если мод есть у игрока.
  • Сборка из исходников: gradlew build (Windows: gradlew.bat build), jar появится в build/libs/. Для разработки: gradlew runClient / gradlew runServer (всё лежит в run/scriptcraft/).
  • При первом запуске мод создаст папку scriptcraft/ и скопирует туда примеры скриптов и ресурсов.
  • Requires Minecraft 1.20.1 and Forge 47.x (Java 17).
  • Put scriptcraft-<version>.jar into the mods folder of the server and every client: screens, custom blocks and texture sync only work when the player has the mod.
  • Build from source: gradlew build (Windows: gradlew.bat build), the jar lands in build/libs/. For development: gradlew runClient / gradlew runServer (files live in run/scriptcraft/).
  • On first start the mod creates the scriptcraft/ folder and copies example scripts and resources into it.

2. Папка scriptcraft/2. The scriptcraft/ folder

Всё, что относится к моду, лежит в одной папке рядом с mods (на сервере — рядом с server.properties):

Everything the mod uses lives in one folder next to mods (on a server — next to server.properties):

scriptcraft/
  config.toml              (настройки / settings)
  scripts/                 (*.sc, UTF-8; подпапки читаются; "-имя.sc" — выключен)
    welcome.sc
    menu.sc
    ruby.sc
    -hud.sc                (пример HUD, выключен / disabled: /sc enable hud)
  variables/
    variables.json         (постоянные переменные / persistent variables)
    variables-20261104-153000.json   (резервные копии / backups)
  resources/
    assets/<namespace>/...   (текстуры, модели, lang — сервер отправит игрокам)
    data/<namespace>/...     (лут, теги, рецепты — только сервер)
  cache/assets/...         (клиент: ресурсы, полученные с серверов)

Файлы прошлой версии *.sk при запуске мода переименовываются в *.sc.

Files from the previous version, *.sk, are renamed to *.sc when the mod starts.

3. Первый скрипт3. Your first script

Создайте файл scriptcraft/scripts/hello.sc (кодировка UTF-8, отступ — 4 пробела или Tab) и выполните в игре /sc reload hello:

Create scriptcraft/scripts/hello.sc (UTF-8, indent with 4 spaces or a Tab) and run /sc reload hello in game:

on join:
    send "&aПривет, %player%!" to player

command /hello:
    send "&bHello, %player%! Ты написал: %args%" to player
    play sound entity.experience_orb.pickup to player

Ошибки в скрипте (с номером строки) попадают в журнал студии (F3 + `) и в лог сервера. Короткий итог команды всплывает уведомлением, а не сообщением в чат. Весь синтаксис — на вкладке Документация, готовые скрипты — в Примерах.

Script errors (with line numbers) go to the studio journal (F3 + `) and the server log. A command's short result pops up as a notice, not a chat line. All syntax is on the Docs tab, complete scripts are in Examples.

4. Команды мода4. Mod commands

/scriptcraft, /sc и /script — одно и то же. Нужен уровень оператора 2. Имена скриптов дополняются по Tab, .sc можно не писать.

/scriptcraft, /sc and /script are the same command. Operator level 2 is required. Script names tab-complete, .sc is optional.

Блоки и предметы: настоящие id + без перезапуска. define block/item, которые есть в скриптах при запуске, регистрируются под своими id (example:ruby_block): ванильные /give, F3, автодополнение, поворот facing. Новые после /sc reload появляются сразу во временных слотах scriptcraft:dyn_block_N / dyn_item_N (игроки увидят в чате «перезапустите клиент…»), а после перезапуска сервера и клиента переезжают на настоящие id вместе с поставленными блоками и предметами. Скрипты клиентам не нужны: при первом входе на сервер с новыми id клиент запоминает их, Forge просит перезапустить игру — после этого вход работает. Что где — /sc ids. Blocks and items: real ids + no restart. define block/item present in the scripts at startup are registered under their own ids (example:ruby_block): vanilla /give, F3, tab completion, facing rotation. New ones after /sc reload appear at once in temporary slots scriptcraft:dyn_block_N / dyn_item_N (players see "restart the client…" in chat) and after a server and client restart move to their real ids together with placed blocks and items. Clients don't need the scripts: on the first join to a server with new ids the client remembers them and Forge asks to restart the game — after that joining works. /sc ids shows which is which.

5. Конфиг5. Config

Файл scriptcraft/config.toml создаётся при первом запуске (ниже — значения по умолчанию; language = "ru" переключит сообщения мода на русский). После правки файла выполните /sc config reload — перезапуск не нужен. Описание каждого параметра — в разделе Конфиг.

scriptcraft/config.toml is created on first start (defaults below; language = "ru" switches mod messages to Russian). After editing the file run /sc config reload — no restart needed. Every option is described in the Config section.

[general]
    language = "en"
    enableTemporaryVariables = true
    variablesSaveIntervalSeconds = 300
    variableBackups = 5
    maxScriptSteps = 10000
    maxScriptMillis = 50
    logScriptLoadTimes = false
    allowCommandEffects = true
    targetedPlayerRange = 50

[resources]
    syncResourcesToClients = true
    maxResourceSizeMb = 32
    resourceChunkSizeKb = 256

[effectCommands]
    enableEffectCommands = false
    effectCommandToken = "?"
    effectCommandsRequireOp = true

Путь scriptcraft/config.toml ещё не проверен на живой сборке Forge. Если при запуске в логе ошибка про config, в техническом описании сказано, как вернуть стандартное место config/scriptcraft-common.toml.

The scriptcraft/config.toml path has not been verified on a live Forge build yet. If the log shows a config error at startup, the technical doc explains how to switch back to the standard config/scriptcraft-common.toml.
